# Cue downloads

Installers for [Cue](https://saycue.app), the live meeting copilot. This repository holds
release files only; the source is private.

Download the latest version from **[saycue.app/download](https://saycue.app/download)** or the
[latest release](../../releases/latest).

| Platform | File |
|---|---|
| macOS (Apple silicon) | `Cue-<version>-arm64.dmg` |
| macOS (Intel) | `Cue-<version>-x64.dmg` |
| Windows | `Cue-Setup-<version>.exe` |
| Linux | `Cue-<version>.AppImage`, `.deb` |
| Android | `Cue-<version>.apk` |

Support: support@saycue.app
